# Security policy

## Supported code

Security fixes are made on the default branch of
https://github.com/allenki1eo/HIE. Debug Android APKs in `android/dist/` are
sideload builds, not a store release, and are not a supported security boundary.

## Reporting a vulnerability

Please do not open a public issue for a security report.

Use a private GitHub security advisory:

https://github.com/allenki1eo/HIE/security/advisories/new

If that page is unavailable, contact [@allenki1eo](https://github.com/allenki1eo)
directly and include a description, the affected path, and a way to reproduce
the problem.

We will acknowledge the report and agree on a fix before any public write-up.
