# research/

| Folder | Purpose |
|---|---|
| `notebooks/` | exploratory analysis. Anything that informs a decision must be re-run as a `hie bench` experiment before it is quoted |
| `experiments/` | one folder per EXP-ID with its hypothesis, protocol and a link to its run directory and commit |
| `algorithms/` | design notes for candidate HIE algorithms. They stay proposals until the approval gate is passed |
| `papers/` | reading notes (never PDFs of copyrighted papers). The verified bibliography lives in `docs/literature-review.md` |
